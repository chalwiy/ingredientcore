개인정보와 문의 정보 처리 안내

사이트 열람, 문의 작성·복사 및 이메일 발송 과정에서 정보가 어떻게 처리되는지 안내합니다.

개정일: 2026년 10월 3일.

IngredientCore는 Bespring Chemical의 자회사인 鸿源配料有限公司의 식품 원료 수출 브랜드입니다. 이 안내는 사이트 열람과 문의 기능 이용에 적용됩니다.

문의는 본인의 이메일에서 직접 발송합니다

입력한 내용으로 이메일 초안을 열거나 문의 전문을 복사할 수 있습니다. 받는 사람과 내용을 확인한 뒤 본인의 이메일에서 직접 보내 주세요. 사이트 열람, 복사 및 이메일 발송 시 정보는 각 단계에 맞는 방식으로 처리됩니다.

  • 입력하는 정보
  • 문의 링크에 포함된 정보
  • 이메일 초안 열기
  • 문의 내용 복사
  • 쿠키·브라우저 저장소·페이지 리소스
  • 호스팅과 접속 기록
  • 이메일·전화·WhatsApp·외부 링크
  • 개인정보 문의 및 안내 변경

입력하는 정보

양식의 필수 항목은 이름, 회사 이메일, 품목명 또는 목표 기능입니다. 견적, 샘플, 제품 자료, 용도 상담 중 문의 유형을 선택할 수 있습니다. 회사명, 납품 목적지, 용도, 기능, 예상 수량, 희망 시점, 규격 및 자료 요청 목적은 필요에 따라 입력해 주세요.

상담에 필요한 정보만 입력해 주세요. 기밀 배합, 비밀번호, 결제 정보 또는 민감한 개인정보는 입력하지 마세요. 첨부 파일은 본인의 메일 앱이나 웹메일에서 추가할 수 있습니다.

문의 링크에 포함된 정보

제품이나 용도 페이지의 문의 링크에는 품목, 용도, 목표 기능, 요청 문서, 목적 또는 참조 페이지 식별자가 포함될 수 있습니다. 문의 페이지는 이 정보를 양식에 미리 입력하고 확인 가능한 참조 페이지를 초안에 추가합니다.

URL은 브라우저 기록, 공유 링크나 호스팅 로그에 남을 수 있습니다. URL에 개인정보나 기밀 정보를 넣지 마세요. 양식에 직접 입력한 내용을 사이트 스크립트가 URL에 추가하지는 않습니다.

이메일 초안 열기

필수 항목 확인과 문의문 작성은 브라우저에서 이루어집니다. 내용을 확인한 뒤 본인의 이메일에서 직접 보내 주세요.

‘이메일 초안 열기’를 누르면 문의 전문을 표시하고, mailto 링크로 받는 사람, 제목과 본문을 기본 메일 앱에 전달합니다. 내용을 확인한 뒤 직접 보내 주세요. 초안의 저장 또는 동기화는 메일 앱의 설정을 따릅니다.

내용이 길 경우 문의 전문을 표시하므로 복사해 새 메일에 붙여 넣으실 수 있습니다. 발송 및 수신 상태는 이용하시는 이메일 서비스에서 확인해 주세요.

문의 내용 복사

‘문의 내용 복사’를 누르면 받는 사람, 제목과 본문을 브라우저의 클립보드에 기록합니다. 자동 복사를 사용할 수 없으면 표시된 문의 전문을 수동으로 복사해 메일에 붙여 넣어 주세요.

클립보드 기록과 기기 간 동기화는 사용 중인 기기의 설정을 따릅니다. 사이트는 사용자가 복사를 선택한 문의 내용을 기록합니다.

쿠키·브라우저 저장소·페이지 리소스

사이트 스크립트는 문의 내용을 보관하는 데 쿠키, localStorage, sessionStorage 또는 IndexedDB를 사용하지 않습니다. 서비스 워커를 등록하거나 분석 이벤트를 전송하지도 않습니다. 스타일, 스크립트와 이미지는 이 사이트에서 제공하며 글꼴은 기기의 글꼴을 사용합니다.

브라우저는 페이지를 캐시하거나 입력란을 자동으로 채우거나 이전 입력을 복원할 수 있습니다. JavaScript를 꺼도 페이지를 열람하고 문의 페이지의 이메일 양식이나 영업 이메일을 이용하실 수 있습니다.

호스팅과 접속 기록

페이지에 접속하면 호스팅 서비스가 IP 주소와 요청 URL 등 기술 정보를 수신합니다. 호스팅 및 보안 서비스는 각 서비스 운영 방침에 따라 접속 기록을 보관할 수 있습니다.

이 사이트를 GitHub Pages에서 제공할 경우 GitHub는 보안을 위해 방문자 IP 주소를 기록하고 보관한다고 안내합니다. 자세한 사항은 GitHub Pages의 데이터 수집 안내를 확인해 주세요.

이메일·전화·WhatsApp·외부 링크

발송한 이메일에 포함된 정보는 발신자와 수신자가 이용하는 이메일 서비스에서 처리합니다. 전화와 WhatsApp 정보는 해당 통신 서비스에서 처리합니다. 전송 상태는 사용하시는 서비스에서 확인해 주세요.

WhatsApp이나 외부 기술 자료 링크를 열면 해당 서비스로 이동합니다. 사이트는 브라우저에 참조 페이지의 URL을 전달하지 않도록 설정합니다. 외부 서비스는 접속 처리에 필요한 정보를 자체 운영 방침에 따라 처리합니다.
