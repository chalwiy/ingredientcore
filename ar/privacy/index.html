الخصوصية وبيانات الطلب

كيفية معالجة البيانات عند تصفح الموقع أو إعداد طلب أو التواصل بالبريد الإلكتروني.

آخر مراجعة: 3 أكتوبر 2026.

IngredientCore هي علامة تصدير المكونات الغذائية لشركة 鸿源配料有限公司، التابعة لشركة Bespring Chemical. يوضّح هذا الإشعار طريقة عمل الموقع ونموذج الطلب.

أنت من يرسل الطلب من حساب البريد

يعدّ النموذج مسودة بريد أو نصاً للنسخ. تختلف طريقة معالجة البيانات في التصفح والنسخ وخدمة البريد.

  • البيانات التي تدخلها في النموذج
  • بيانات المنتج والتطبيق في الروابط
  • إعداد مسودة بريد
  • نسخ نص الطلب
  • ملفات تعريف الارتباط والتخزين والموارد
  • الاستضافة وسجلات الوصول
  • البريد والهاتف وواتساب والروابط الخارجية
  • التواصل بشأن الخصوصية

البيانات التي تدخلها في النموذج

الاسم والبريد الإلكتروني للعمل والمنتج أو الوظيفة المطلوبة حقول إلزامية. اختر عرض سعر أو عينة أو وثائق المنتج أو مساعدة في الاختيار. الحقول الأخرى اختيارية.

أدخل البيانات اللازمة لمناقشة الطلب فقط. تجنّب إدخال تركيبات سرية أو كلمات مرور أو بيانات دفع أو معلومات شخصية حساسة. أضف المرفقات من تطبيق البريد عند الحاجة.

بيانات المنتج والتطبيق في الروابط

قد يتضمن رابط صفحة التواصل بيانات المنتج أو التطبيق أو الوظيفة أو الوثائق أو غرض التجربة أو مفتاح الصفحة المرجعية. يستخدم النموذج هذه البيانات لملء الحقول ويدرج الصفحة المعروفة في الرسالة.

قد تظهر عناوين الصفحات في سجل المتصفح أو الروابط المتداولة أو سجلات الاستضافة. تجنّب وضع بيانات شخصية أو سرية في الرابط. لا تنقل نصوص الموقع البيانات المكتوبة في النموذج إلى رابط الصفحة.

إعداد مسودة بريد

يتحقّق النموذج من الحقول الإلزامية ويعدّ النص في المتصفح. يُنقل المحتوى إلى تطبيق البريد عبر رابط mailto عند طلب فتح المسودة.

عند الضغط على «فتح مسودة البريد»، يعرض الموقع النص الكامل ويمرّر المستلم والموضوع والرسالة إلى تطبيق البريد المهيّأ. راجع الرسالة وأرسلها من بريدك. قد تحفظ خدمة البريد المسودة أو تزامنها وفق إعداداتك.

إذا تجاوز النص طول رابط البريد المعتمد، يظهر النص للنسخ اليدوي. يعتمد الإرسال وتأكيد التسليم على خدمة البريد.

نسخ نص الطلب

عند الضغط على «نسخ نص الطلب»، يطلب الموقع من المتصفح نسخ النص والعنوان والموضوع. قد يسمح المتصفح بالنسخ أو يطلب الإذن أو يحظره. إذا تعذّر النسخ التلقائي، انسخ النص المحدّد والصقه في رسالة جديدة.

قد يحفظ نظام التشغيل سجل الحافظة أو يزامنه بين الأجهزة. يكتب الموقع نص الطلب في الحافظة عند الضغط على زر النسخ.

ملفات تعريف الارتباط والتخزين والموارد

لا تحفظ نصوص الموقع الطلبات في ملفات تعريف الارتباط أو localStorage أو sessionStorage أو IndexedDB. يستخدم الموقع ملفاته الخاصة وخطوط الجهاز، ولا يضم أدوات تحليل للزيارات أو نماذج خارجية أو برامج خدمة في الخلفية.

قد يحتفظ المتصفح بموارد الموقع مؤقتاً أو يملأ الحقول تلقائياً أو يستعيد النص عند فتح علامة تبويب. عند تعطيل JavaScript، يمكنك استخدام بيانات التواصل المباشر أو قالب البريد.

الاستضافة وسجلات الوصول

تتلقى خدمة الاستضافة عند فتح الصفحة بيانات تقنية، مثل عنوان IP وعنوان الصفحة المطلوبة. قد تحتفظ خدمات الاستضافة والأمان بسجلات الوصول.

توضح GitHub أن عناوين IP لزوار المواقع المستضافة على GitHub Pages تُسجّل وتُحفظ لأغراض الأمان. كيفية معالجة البيانات في GitHub Pages (علامة تبويب جديدة).

البريد والهاتف وواتساب والروابط الخارجية

عند إرسال رسالة، تتلقى IngredientCore البيانات التي تدرجها فيها. تعالج الرسالة كذلك خدمات البريد للمرسل والمستلم. عند التواصل بالهاتف أو واتساب، يعالج مزوّد الاتصال الذي اخترته البيانات اللازمة.

تفتح روابط واتساب والمراجع التقنية خدمات خارجية. تطلب الصفحات من المتصفح حجب عنوان الصفحة المرجعية عند الانتقال. تتلقى الخدمة الخارجية البيانات الفنية اللازمة لمعالجة الزيارة.
