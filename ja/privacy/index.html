個人情報・お問い合わせ

本サイトを閲覧したり、食材のお問い合わせを準備する際には何が起こるか。

最終改定日: 2026年10月3日.

IngredientCoreは、Bespring Chemicalの子会社である清源の分譲の食品原料輸出ブランドです。 当ウェブサイトの閲覧やお問い合わせツールの利用についてご案内しております。

問い合わせを準備して、送信してください。

フォームは、メールのドラフトやテキストを作成してコピーします。 当ウェブサイトの受信トレイにお問い合わせを送信しないでください。 電子メールサービスの利用をブラウジング、コピー、および利用する際は、以下の説明に別途データ処理を含みます。

  • ご希望の情報を入力してください
  • リンク内の製品およびアプリケーションコンテキスト
  • 電子メールのドラフトの準備
  • 問い合わせのコピー
  • クッキー、ブラウザのストレージ、ページリソース
  • ホスティングおよび技術アクセス情報
  • メール、電話、WhatsApp、外部リンク
  • 個人情報保護方針

ご希望の情報を入力してください

お問い合わせフォームでは、お名前、ビジネスメール、商品、ターゲット機能など、ご要望に応じて対応させていただきます。 要求タイプを選ぶ:プロダクトか引用語句、サンプル、文書、または適用および選択。 任意分野は会社、宛先市場、食糧適用、ターゲット機能、量およびタイミング、指定、文書または証明書、検討または試験目的および他の質問を含んでいます。

ご要望をご相談いただくために必要な情報のみをご提供します。 機密の公式、パスワード、支払いの詳細、または機密性の高い個人情報を避けてください。 ファイルのアップロード機能はありません。適切な場合は、添付ファイルを追加できます。

リンク内の製品およびアプリケーションコンテキスト

コンタクトページへのリンクには、URLに商品、アプリケーション、目標、ドキュメントトピック、目的、参照ページのキーが含まれる場合があります。 このページでは、この文脈を使って問い合わせを優先し、草案で認められた参考ページが含まれています。

ブラウザの履歴、共有リンク、ホスティングレコードにURLが表示されることがあります。 これを非感性に保ちましょう。URLに個人情報や機密処方情報を配置しないでください。 フォームに入力した情報は、スクリプトで閲覧URLに追加されません。

電子メールのドラフトの準備

フォームは、必要なフィールドを確認し、問い合わせテキストを作成するために、ブラウザ内のエントリを処理する。 オンラインの送信エンドポイントがない場合、フォームコンテンツをWebサイトサーバーに送信しません。

「メールの草案を開く」を選択すると、ページは完全な問い合わせを表示し、受信者、件名、およびメールリンクを介して設定された電子メールアプリケーションにメッセージが表示されます。 草案を見直し、それを自分で送る。 電子メールアプリケーションまたはWebメールサービスは、設定に応じて、送信する前に草案を保存または同期することができます。

テキストが信頼できるメールリンクで長すぎる場合は、代わりにページが手動でコピーするための表示になります。 ドラフトを開くと、メールが送信されたり受信したか確認できません。

問い合わせのコピー

「Webメールの問い合わせをコピー」を選択すると、受信者や被写体を含む完全な照会をブラウザのクリップボードAPIを使用してクリップボードに書き込む試みがページになります。 ブラウザは、そのセキュリティルールや設定に応じて、アクションを許可したり、許可を要求したり、ブロックしたりすることができます。 選択可能なテキストも表示されます。 自動コピーが利用できなくなった場合は、デバイスのコピーコマンドを使用してテキストをメールアプリケーションに貼り付けます。

コピーは、お問い合わせを提出しません。 お使いのオペレーティングシステムは、クリップボードの履歴を保持したり、デバイス間でクリップボードのコンテンツを同期したりすることができます。 既存のクリップボードのコンテンツは、ウェブサイトが閲覧できません。

クッキー、ブラウザのストレージ、ページリソース

現在のウェブサイトスクリプトは、クッキーを設定したり、ローカルストレージ、セッションストレージ、インデックス化されたDBを使用して問い合わせを保持しません。 サービスは、サービスワーカーを登録したり、分析イベントを送ったりしません。 同じウェブサイトからページスタイル、スクリプト、画像が提供されます。フォントは、デバイスのインストールされたフォントを使用します。 サードパーティのフォントサービス、埋め込みウィジェット、分析ツール、外部フォームサービスが現在のページに含まれています。

当ウェブサイトでは、ドラフト・セービング機能はありません。 ブラウザは、ページリソースをキャッシュしたり、フィールドの自動入力したり、タブやセッションが復元されたときに入力したテキストを復元したりすることができます。 こちらのブラウザは、お問い合わせツールとは別々です。 JavaScript がなければ、サイトを読んで、連絡先ページのメールテンプレートまたは直接連絡先リンクを使用してください。 ドラフトとコピーボタンは利用できなくなります。

ホスティングおよび技術アクセス情報

このページでは、IPアドレスや要求されたURLなどの技術的な情報を受信するホスティングインフラへのリクエストを受け付けています。 問い合わせフォームが記入されていない場合でも、ホスティングおよびセキュリティサービスはアクセス記録を保持する場合があります。

GitHub ページでこのサイトが提供される場合、GitHub は、訪問者 IP アドレスが記録され、セキュリティ目的のために保存されている状態です。 参照 GitHub ページのデータ収集(新しいタブ). この通知は、ホスティングログ保持期間を指定しません。

メール、電話、WhatsApp、外部リンク

弊社にお問い合わせをいただくと、IngredientCoreがお客様の情報を受け取ることができます。 電子メールプロバイダと受信者のメールサービスも、メッセージを処理する。 応募終了のサイトが欠如しているとは、当社に送信された対応が収集されないという意味ではありません。 電話またはWhatsAppでお問い合わせいただくと、選択した通信プロバイダも参加できます。 当ウェブサイトでは、メールやWhatsAppメッセージが自動送信されず、メッセージ配信の確認は行いません。

WhatsAppリンクと外部技術参照は、それらに従うときに関連した外部サービスを開きます。 本サービスは、独自のプライバシー慣行を持っています。 ブラウザをリクエストするページは、ナビゲート時に参照ページのアドレスを省略します。外部サービスでは、訪問を処理するために必要な情報も受け取ります。
