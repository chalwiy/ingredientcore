プライバシーとお問い合わせ情報の取り扱い

サイトの閲覧、依頼内容の入力・コピー、メールの送信に伴う情報の取り扱いをご案内します。

改定日： 2026年10月3日。

IngredientCoreは、Bespring Chemicalの子会社である鸿源配料有限公司の食品原料輸出ブランドです。この案内は、本サイトの閲覧とお問い合わせ機能の利用に適用します。

お問い合わせはご自身のメールから送信

入力内容からメールの下書きを開くか、内容をコピーできます。宛先と本文を確認し、ご自身のメールから送信してください。サイトの閲覧、コピー、メール送信では、それぞれ異なる仕組みで情報が取り扱われます。

ご入力いただく情報

フォームで必要なのは、お名前、勤務先メールアドレス、品名または求める機能です。見積もり、サンプル、製品資料、用途のご相談から種類をお選びいただけます。会社名、納入先、食品用途、求める機能、予定数量、希望時期、規格、資料の目的は必要に応じてご記入ください。

ご相談に必要な情報に限ってご記入ください。機密の配合情報、パスワード、支払情報、機微な個人情報は入力しないでください。添付資料は、ご自身のメールアプリやウェブメールで追加できます。

お問い合わせリンクに含まれる情報

製品ページや用途ページからのリンクには、品名、用途、求める機能、必要書類、依頼目的、参照元の識別子が含まれる場合があります。お問い合わせページではこれらの情報をフォームに反映し、該当する参照元を下書きに記載します。

URLの情報は、ブラウザーの履歴、共有リンク、ホスティングのアクセス記録に残ることがあります。個人情報や機密情報をURLに含めないでください。フォームに直接入力した情報を、サイトのスクリプトがURLに追加することはありません。

メールの下書きを開く

入力内容の確認と依頼文の作成は、ブラウザー内で行います。依頼文をご確認のうえ、ご自身のメールから送信してください。

「メールの下書きを開く」を選ぶと、依頼内容の全文を表示してから、mailtoリンクで宛先、件名、本文を既定のメールアプリに渡します。送信はご自身で行ってください。下書きの保存や同期は、メールアプリの設定に従います。

依頼文が長い場合は、全文を表示します。コピーしてご自身のメールに貼り付けてください。送信や配信の状況は、ご利用のメールサービスでご確認ください。

依頼内容のコピー

「依頼内容をコピー」を選ぶと、宛先、件名、本文をブラウザーのクリップボードに書き込みます。自動コピーが利用できない場合は、表示された文章を手動でコピーしてメールに貼り付けてください。

クリップボードの履歴と端末間の同期は、ご利用の端末の設定に従います。本サイトは、ご利用者がコピーを選んだ文章を書き込みます。

Cookie・ブラウザーの保存領域・ページの素材

お問い合わせの保存にCookie、localStorage、sessionStorage、IndexedDBを使用しません。Service Workerの登録や分析イベントの送信も行いません。スタイル、スクリプト、画像は本サイトが配信し、文字の表示には端末のフォントを使います。

ブラウザーは、ページのキャッシュ、入力欄の自動補完、以前の入力内容の復元などを行う場合があります。JavaScriptを無効にした場合も、サイトを閲覧し、お問い合わせページのメールひな型や営業窓口のメールアドレスをご利用いただけます。

ホスティングとアクセス記録

ページへのアクセス時には、ホスティングサービスがIPアドレスやリクエスト先のURLなどの技術情報を受け取ります。ホスティングやセキュリティーのサービスは、各サービスの方針に従ってアクセス記録を保持する場合があります。

GitHub Pagesで配信される場合、GitHubはセキュリティー上の目的で訪問者のIPアドレスを記録・保存すると説明しています。詳しくは GitHub Pagesで収集されるデータについての説明をご覧ください。

メール・電話・WhatsApp・外部リンク

メールで送信された内容は、ご利用者と当社が利用するメールサービスで取り扱われます。電話やWhatsAppでご連絡いただく場合は、該当の通信サービスが情報を処理します。送信や配信の状況はご利用のサービスでご確認ください。

WhatsAppや技術資料の外部リンクを開くと、そのサービスへ移動します。ブラウザーには参照元URLを送らないよう指定しています。リンク先では、アクセスの処理に必要な情報が各サービスの方針に従って取り扱われます。

本サイトや送信済みのお問い合わせ、ご提供いただいた情報については、 ingredientcore@bespringchem.comまで、確認に必要な範囲で経緯をお知らせください。
