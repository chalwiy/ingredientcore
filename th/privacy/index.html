ความเป็นส่วนตัวและข้อมูลคำขอ

วิธีจัดการข้อมูลเมื่อคุณเปิดดูเว็บไซต์ เตรียมคำขอ หรือติดต่อฝ่ายขายทางอีเมล

ปรับปรุงล่าสุด: 3 ตุลาคม 2026.

IngredientCore คือแบรนด์ส่งออกส่วนผสมอาหารของบริษัท 鸿源配料有限公司 ซึ่งเป็นบริษัทย่อยของ Bespring Chemical ประกาศนี้อธิบายการเปิดดูเว็บไซต์และการใช้แบบฟอร์มติดต่อ

คุณเป็นผู้ส่งคำขอจากอีเมลของตนเอง

แบบฟอร์มเตรียมอีเมลฉบับร่างหรือข้อความสำหรับคัดลอก การเปิดดูเว็บไซต์ การคัดลอก และการส่งอีเมลมีการจัดการข้อมูลต่างกัน

  • ข้อมูลที่กรอกในแบบฟอร์ม
  • ข้อมูลผลิตภัณฑ์และการใช้งานในลิงก์
  • การเตรียมอีเมลฉบับร่าง
  • การคัดลอกคำขอ
  • คุกกี้ พื้นที่จัดเก็บ และทรัพยากรเว็บไซต์
  • โฮสติ้งและข้อมูลการเข้าถึง
  • อีเมล โทรศัพท์ WhatsApp และลิงก์ภายนอก
  • ช่องทางติดต่อเรื่องความเป็นส่วนตัว

ข้อมูลที่กรอกในแบบฟอร์ม

แบบฟอร์มขอชื่อ อีเมลสำหรับงาน และชื่อผลิตภัณฑ์หรือหน้าที่ที่ต้องการ คุณเลือกขอใบเสนอราคา ตัวอย่าง เอกสาร หรือหารือการเลือกเกรดได้ ช่องอื่นกรอกตามความจำเป็น

กรอกเฉพาะข้อมูลที่จำเป็น กรุณาเว้นสูตรลับ รหัสผ่าน ข้อมูลการชำระเงิน และข้อมูลส่วนบุคคลที่อ่อนไหว เพิ่มไฟล์แนบในโปรแกรมอีเมลของคุณเมื่อจำเป็น

ข้อมูลผลิตภัณฑ์และการใช้งานในลิงก์

ลิงก์หน้าติดต่ออาจระบุผลิตภัณฑ์ การใช้งาน หน้าที่ เอกสาร จุดประสงค์ หรือรหัสหน้าอ้างอิง ระบบใช้ข้อมูลนี้เพื่อกรอกแบบฟอร์มล่วงหน้าและใส่หน้าอ้างอิงที่รู้จักในข้อความ

URL อาจปรากฏในประวัติเบราว์เซอร์ ลิงก์ที่แชร์ และบันทึกโฮสติ้ง กรุณาเว้นข้อมูลส่วนบุคคลหรือสูตรลับใน URL สคริปต์ของเว็บไซต์ไม่เพิ่มข้อมูลที่ผู้ใช้กรอกลงใน URL

การเตรียมอีเมลฉบับร่าง

ระบบตรวจสอบช่องบังคับและสร้างข้อความในเบราว์เซอร์ เมื่อเปิดฉบับร่าง ระบบใช้ลิงก์ mailto เพื่อส่งข้อมูลไปยังโปรแกรมอีเมลที่ตั้งไว้

เมื่อเลือก «เปิดอีเมลฉบับร่าง» เว็บไซต์จะแสดงข้อความทั้งหมดและส่งชื่อผู้รับ หัวข้อ และเนื้อหาไปยังโปรแกรมอีเมล ตรวจทานและส่งจากโปรแกรมนั้น บริการอีเมลอาจบันทึกหรือซิงค์ฉบับร่างตามการตั้งค่าของคุณ

หากข้อความยาวเกินขีดจำกัดของลิงก์ เว็บไซต์จะแสดงข้อความให้คัดลอกเอง การส่งและการยืนยันการส่งถึงขึ้นอยู่กับบริการอีเมลของคุณ

การคัดลอกคำขอ

เมื่อเลือก «คัดลอกข้อความคำขอ» เว็บไซต์จะขอให้เบราว์เซอร์คัดลอกข้อความพร้อมผู้รับและหัวข้อ เบราว์เซอร์อาจอนุญาต ขอสิทธิ์ หรือปฏิเสธ หากคัดลอกอัตโนมัติไม่ได้ ให้คัดลอกข้อความที่เลือกไว้แล้ววางในอีเมลใหม่

ระบบปฏิบัติการอาจเก็บประวัติคลิปบอร์ดหรือซิงค์ข้อมูลระหว่างอุปกรณ์ เว็บไซต์เขียนข้อความลงคลิปบอร์ดเมื่อคุณกดคัดลอก

คุกกี้ พื้นที่จัดเก็บ และทรัพยากรเว็บไซต์

สคริปต์เว็บไซต์ไม่บันทึกคำขอในคุกกี้ localStorage, sessionStorage หรือ IndexedDB หน้าเว็บใช้ไฟล์ของเว็บไซต์และแบบอักษรจากอุปกรณ์ ไม่มีแบบฟอร์มภายนอก ระบบวิเคราะห์การเข้าชม หรือ service worker

เบราว์เซอร์อาจแคชไฟล์ กรอกช่องอัตโนมัติ หรือกู้ข้อความเมื่อเปิดแท็บอีกครั้ง เมื่อปิด JavaScript ยังใช้ข้อมูลติดต่อและแม่แบบอีเมลได้ ปุ่มเปิดฉบับร่างและปุ่มคัดลอกจะปิดใช้งาน

โฮสติ้งและข้อมูลการเข้าถึง

เมื่อเปิดหน้าเว็บ โฮสติ้งจะได้รับข้อมูลทางเทคนิค เช่น ที่อยู่ IP และ URL ที่ร้องขอ ผู้ให้บริการโฮสติ้งและระบบรักษาความปลอดภัยอาจเก็บบันทึกการเข้าถึง

GitHub ระบุว่าที่อยู่ IP ของผู้เข้าชมเว็บไซต์ที่โฮสต์บน GitHub Pages จะถูกบันทึกและเก็บเพื่อความปลอดภัย การเก็บข้อมูลของ GitHub Pages (เปิดแท็บใหม่).

อีเมล โทรศัพท์ WhatsApp และลิงก์ภายนอก

เมื่อคุณส่งอีเมล IngredientCore จะได้รับข้อมูลในข้อความ ผู้ให้บริการอีเมลของผู้ส่งและผู้รับจะประมวลผลข้อความด้วย การโทรหรือใช้ WhatsApp เกี่ยวข้องกับผู้ให้บริการสื่อสารที่คุณเลือก

ลิงก์ WhatsApp และแหล่งอ้างอิงทางเทคนิคจะเปิดบริการภายนอก เราขอให้เบราว์เซอร์งดส่ง URL ของหน้าอ้างอิงเมื่อเปิดลิงก์ ผู้ให้บริการภายนอกยังได้รับข้อมูลทางเทคนิคที่จำเป็นต่อการเปิดหน้า

ช่องทางติดต่อเรื่องความเป็นส่วนตัว

หากมีข้อสงสัยเกี่ยวกับเว็บไซต์ คำขอที่ส่ง หรือข้อมูลของคุณ โปรดส่งอีเมลไปที่ ingredientcore@bespringchem.comระบุเฉพาะข้อมูลที่ช่วยค้นหาการติดต่อหรือระบุการเปิดดูเว็บไซต์
