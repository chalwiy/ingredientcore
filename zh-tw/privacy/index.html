隱私和查詢資料。

當您瀏覽網站或準備配料查詢時會發生什麼。

上次修訂： 2026年10月3日.

IngredientCore 是鴻源配料有限公司的食品配料出口品牌；鴻源配料有限公司是 Bespring Chemical 的子公司。本宣告說明瀏覽本靜態網站及使用詢盤工具的相關事項。

您準備了查詢,您傳送了它。

該表單會建立電子郵件草稿或要複製的文字。 它不會將您的查詢提交到網站收件箱。 瀏覽、複製和使用電子郵件服務涉及單獨的資料處理,詳情如下。

  • 您選擇提供的資訊
  • 連結中的產品和應用環境
  • 準備電子郵件草稿
  • 複製查詢
  • Cookie、瀏覽器儲存和頁面資源
  • 託管和技術訪問資訊
  • 電子郵件,電話,WhatsApp和外部連結
  • 隱私問題和通知更新

您選擇提供的資訊

詢價表格要求您的姓名, 業務電子郵件和產品或目標功能. 您可以選擇請求型別:產品或報價、樣品、文件或應用和選擇。 可選欄位包括公司、目標市場、食品應用、目標功能、數量和時間、規格、檔案或證書、審查或試驗目的以及其他問題。

僅提供討論您的請求所需的資訊。 避擴音供完全保密的公式、密碼、付款詳情或敏感的個人資訊。 沒有檔案上傳功能;附件可以在您自己的電子郵件應用程式中新增。

連結中的產品和應用環境

指向聯絡頁面的連結可以包括產品、應用程式、目標、文件主題、目的或 URL 中參考頁面鍵。 該頁面使用此上下文預填充查詢,並在草稿中包含已識別的參考頁面。

網頁網址可以出現在瀏覽器歷史記錄、共享連結和託管記錄中。 請保持上下文不敏感:不要在網址中放置個人詳細資訊或機密配方資訊。 您在表單中輸入的資訊不會被我們的指令碼新增到瀏覽 URL 中。

準備電子郵件草稿

表單在瀏覽器中處理您的輸入,以檢查必填欄位並建立查詢文字。 它沒有線上提交端點,也不會將表單內容傳送到我們的網站伺服器。

當您選擇“開啟電子郵件草稿”時,該頁面將顯示完整的查詢並透過mailto連結將收件人、主題和訊息傳遞到您配置的電子郵件應用程式。 審查草稿並親自傳送。 電子郵件應用程式或 Web 郵件服務可能會根據其設定在您傳送之前儲存或同步草稿。

如果文字太長,無法提供可靠的電子郵件連結,則頁面將顯示該文字以供手動複製。 開啟草稿並不確認電子郵件已傳送或收到。

複製查詢

當您選擇“複製查詢到網路郵件”時,該頁面會嘗試使用瀏覽器的剪貼簿 API 將完整的查詢(包括收件人和主題)寫入您的剪貼簿。 瀏覽器可以根據其安全規則和設定允許該操作、請求許可或阻止它。 該頁面還顯示可選擇的文字。 如果無法使用自動複製,請使用裝置的複製命令將文字貼上到電子郵件應用程式中。

複製不提交查詢。 您的作業系統可能會保留剪貼簿歷史記錄或在裝置之間同步剪貼簿內容,具體取決於您的設定。 該網站不會讀取您現有的剪貼簿內容。

Cookie、瀏覽器儲存和頁面資源

當前的網站指令碼不設定 cookie 或使用 localStorage、sessionStorage 或 IndexedDB 來保留查詢。 它們不會註冊服務工作者或傳送分析事件。 頁面樣式、指令碼和影象均來自同一網站;字型使用裝置上安裝的字型。 當前頁面中不包含任何第三方字型服務、嵌入式小部件、分析工具或外部表單服務。

網站沒有儲存草稿功能。 當恢復標籤或會話時,您的瀏覽器仍可能快取頁面資源、自動填充欄位或恢復輸入的文字。 這些瀏覽器功能與我們的查詢工具分開。 沒有 JavaScript,您可以閱讀網站並使用聯絡人頁面的電子郵件模板或直接聯絡連結;草稿和複製按鈕不可用。

託管和技術訪問資訊

提供網頁涉及到向託管基礎設施發出請求,託管基礎設施接收技術資訊,如 IP 地址和請求的 URL。 即使查詢表格沒有提交您的條目,託管和安全服務也可能保留訪問記錄。

如果本網站透過 GitHub Pages 提供,GitHub 宣告訪問者的 IP 地址將被記錄並儲存以保證安全。 GitHub 頁面資料收集(新標籤). 本通知未指定託管日誌保留期限。

電子郵件,電話,WhatsApp和外部連結

當您向我們傳送詢問時,IngredientCore會收到您所提供的資訊。 您的電子郵件提供商和收件人的電子郵件服務也會處理該訊息。 網站缺乏提交端點並不意味著傳送給公司的信件從未被收集。 透過電話或WhatsApp聯絡我們也涉及您選擇的通訊提供商。 本網站不會自動傳送電子郵件或WhatsApp訊息,也無法確認訊息的遞送。

WhatsApp 連結和外部技術參考在您點選時會開啟相關的外部服務。 這些服務有其自己的隱私政策。 我們的網頁要求瀏覽器在導航離開時省略引用網頁地址;外部服務仍然會收到處理您訪問所需的資訊。
