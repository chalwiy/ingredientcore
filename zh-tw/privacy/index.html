網站隱私與採購詢問資料

了解瀏覽網站、填寫採購需求、複製內容及寄出郵件時，各環節如何處理資料。

修訂日期： 2026年10月3日。

IngredientCore 是鴻源配料有限公司的食品原料出口品牌。鴻源配料有限公司為 Bespring Chemical 的子公司。本說明適用於本網站瀏覽和詢問工具。

由您選擇何時寄出

網站在瀏覽器中開啟郵件草稿或可複製的文字，採購詢問由您核對後透過自己的信箱寄出。瀏覽網站、複製文字和使用郵件服務涉及不同的資料處理。

  • 您選擇提供的資訊
  • 詢問連結中的產品與應用資訊
  • 開啟郵件草稿
  • 複製詢問內容
  • Cookie、瀏覽器儲存與頁面資源
  • 網站代管與瀏覽記錄
  • 郵件、電話、WhatsApp 與外部連結
  • 隱私諮詢與說明更新

您選擇提供的資訊

表單需要姓名、公司電子郵件及原料品名或目標功能。可選擇詢價、樣品、資料或應用諮詢。公司、交貨地點、食品用途、製程目標、數量、時間、規格與資料用途可按需要填寫。

請只提供討論詢問所需的資訊，避免填寫機密配方、密碼、付款資料或敏感個人資訊。如需共享附件，請在您自己的郵件程式或網頁版信箱中添加。

詢問連結中的產品與應用資訊

產品頁、應用頁等站內連結可在網址中攜帶產品、應用、目標功能、文件、用途或來源頁標識。聯絡頁利用這些資訊預先帶入表單，並將可識別的來源頁加入草稿。

網址可能出現在瀏覽記錄、分享連結或主機日誌中，請使用非敏感的產品和應用資訊。表單中手動填寫的內容不會由本網站腳本寫入網址。

開啟郵件草稿

表單在瀏覽器內核對必填欄位，並生成詢問內容。您填寫的內容保留在打開的頁面，由您通過自己的信箱寄出。

按下「開啟郵件草稿」，頁面會顯示完整內容，並嘗試透過 mailto 連結把收件人、主旨和內文交給已設定的郵件程式。請自行核對並寄出。草稿將依郵件程式的設定儲存或同步。

內容過長時，網站會提供完整文字供手動複製。寄送及送達狀態可在自己的信箱確認。

複製詢問內容

按下「複製詢問內容」，網站會嘗試透過瀏覽器的剪貼簿功能寫入收件人、主旨及完整文字。自動複製不可用時，請在頁面上手動選取文字，複製至自己的信箱。

剪貼簿歷史記錄與跨裝置同步依裝置的設定處理。網站僅寫入您當次選擇複製的文字。

Cookie、瀏覽器儲存與頁面資源

網站腳本不使用 Cookie、localStorage、sessionStorage 或 IndexedDB 來保存詢問，也不注冊 Service Worker 或寄出分析事件。樣式、腳本和圖片由本站提供，字體使用設備自帶字體。

瀏覽器本身可能快取頁面、自動填寫或還原先前輸入。停用 JavaScript 時，仍可瀏覽網站，並使用聯絡頁的郵件範本或直接聯絡業務。

網站代管與瀏覽記錄

打開網頁時，網站代管服務會接收 IP 位址、請求網址等技術資訊。代管及資安服務可依其規則保留瀏覽記錄。

本站透過 GitHub Pages 提供時，GitHub 說明其為安全目的記錄並保存訪問者 IP 地址。可查閱 GitHub Pages 資料收集說明瞭解代管服務的資料處理。

郵件、電話、WhatsApp 與外部連結

您透過自己的電子郵件寄出採購詢問後，郵件中提供的資訊將由您所選的郵件服務以及收件方的郵件服務處理。電話和 WhatsApp 由各通訊服務處理。寄出和送達狀態由您使用的服務提供。

點擊 WhatsApp 或外部技術資料連結后，會進入相應的網站或服務。外部服務根據自身規則處理訪問，本網站請求瀏覽器省略來源頁地址。外部服務仍會接收處理訪問所需的資訊。

隱私諮詢與說明更新

如對網站、已寄出的詢問或您提供的資訊有疑問，請發郵件至 ingredientcore@bespringchem.com，說明必要的訪問或溝通背景。請避免附帶無關的敏感資訊。

聯絡地址：江蘇省徐州市云龍區Greenland Linghai 6 號樓 10 層，郵編 221000。 查看聯絡方式與郵件詢問說明。

如果您需要了解已寄出詢問的訪問範圍或保留時間，請在提供需要特殊處理的資訊前通過上述信箱聯絡。
