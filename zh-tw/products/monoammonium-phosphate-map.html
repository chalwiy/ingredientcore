產品概述

什么是磷酸二氫銨？

磷酸二氫銨又稱磷酸一銨，化學式為 NH₄H₂PO₄。它與磷酸氫二銨（DAP）的成分不同，應按具體用途和檢驗方法分別比較。

常用名稱：磷酸一銨、磷酸單銨。

MAP 採購常見問題

MAP 指哪一種磷酸銨？

MAP 是磷酸二氫銨，又稱磷酸一銨。訂貨名稱應註明完整名稱和所需食等級要求。

P₂O₅ 指標代表 MAP 純度嗎？

以 P₂O₅ 表示的是磷含量，MAP 含量需按相應化合物方法測定。比較時請確認單位、方法和乾基或原樣基準。

洽詢時要指定粉末還是顆粒嗎？

可說明現有投料和操作方式，並索取預計供應的等級的實際型態、粒徑及申報成分。

MAP 能否等量替代 DAP？

MAP 與磷酸氫二銨（DAP）是不同的銨鹽。應根據營養和酸堿目標，在完整配方中試驗。 了解磷酸氫二銨（DAP）。

申請 MAP 樣品和資料需要什么？

提供用途、試驗目標、所需規格、數量和目的地，並註明需要的規格書、TDS、COA、SDS 或證書。
