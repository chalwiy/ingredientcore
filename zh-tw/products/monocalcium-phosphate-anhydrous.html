產品概述

什麼是無水 MCP?

無水磷酸鈣是無水結晶的磷酸二氫鈣。 本頁面介紹的是無水物。 比較水合物材料時,請檢視單獨的 MCP 頁面及其源記錄。 單憑MCP的縮寫並不能確定這兩種形式。

也被稱為: 磷酸二氫鈣(無水)

無水 MCP 是否意味著延遲釋放級別?

沒有 水合物名稱標識材料,而反應行為必須記錄在特定的商業級別和測試中。 不要將競爭對手的等級反應特徵分配給另一個來源。

中和值是否與反應速度相同?

沒有 請求中和值的定義和方法,然後分別檢查反應試驗和過去時間資料。 兩者都屬於全面膨鬆系統的審查。

我可以比較無水 MCP 和重量相同的 MCP 單水合物嗎?

不能假定同等權重的替代。 將材料形式、分析表示式和完整的碳酸氫鹽/酸系統分開,並在定義的流程中評估指定候選物。

請求表格特定規格、TDS與反應和顆粒資訊(如有 ) 、 代表或樣品COA和SDS。 包括食品、測試目標、數量和目的地。 免費樣品安排和適用的證書範圍與銷售商討論。
