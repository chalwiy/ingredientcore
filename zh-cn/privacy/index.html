隐私和查询数据。

当您浏览网站或准备配料查询时会发生什么。

上次修订： 2026年10月3日.

IngredientCore 是鸿源配料有限公司的食品配料出口品牌；鸿源配料有限公司是 Bespring Chemical 的子公司。本声明说明浏览本静态网站及使用询盘工具的相关事项。

您准备了查询,您发送了它。

该表单会创建电子邮件草稿或要复制的文本。 它不会将您的查询提交到网站收件箱。 浏览、复制和使用电子邮件服务涉及单独的数据处理,详情如下。

  • 您选择提供的信息
  • 链接中的产品和应用环境
  • 准备电子邮件草稿
  • 复制查询
  • Cookie、浏览器存储和页面资源
  • 托管和技术访问信息
  • 电子邮件,电话,WhatsApp和外部链接
  • 隐私问题和通知更新

您选择提供的信息

询价表格要求您的姓名, 业务电子邮件和产品或目标功能. 您可以选择请求类型:产品或报价、样品、文档或应用和选择。 可选字段包括公司、目标市场、食品应用、目标功能、数量和时间、规格、文件或证书、审查或试验目的以及其他问题。

仅提供讨论您的请求所需的信息。 避免提供完全保密的公式、密码、付款详情或敏感的个人信息。 没有文件上传功能;附件可以在您自己的电子邮件应用程序中添加。

链接中的产品和应用环境

指向联系页面的链接可以包括产品、应用程序、目标、文档主题、目的或 URL 中参考页面键。 该页面使用此上下文预填充查询,并在草稿中包含已识别的参考页面。

网页网址可以出现在浏览器历史记录、共享链接和托管记录中。 请保持上下文不敏感:不要在网址中放置个人详细信息或机密配方信息。 您在表单中输入的信息不会被我们的脚本添加到浏览 URL 中。

准备电子邮件草稿

表单在浏览器中处理您的输入,以检查必填字段并创建查询文本。 它没有在线提交端点,也不会将表单内容发送到我们的网站服务器。

当您选择“打开电子邮件草稿”时,该页面将显示完整的查询并通过mailto链接将收件人、主题和消息传递到您配置的电子邮件应用程序。 审查草稿并亲自发送。 电子邮件应用程序或 Web 邮件服务可能会根据其设置在您发送之前保存或同步草稿。

如果文本太长,无法提供可靠的电子邮件链接,则页面将显示该文本以供手动复制。 打开草稿并不确认电子邮件已发送或收到。

复制查询

当您选择“复制查询到网络邮件”时,该页面会尝试使用浏览器的剪贴板 API 将完整的查询(包括收件人和主题)写入您的剪贴板。 浏览器可以根据其安全规则和设置允许该操作、请求许可或阻止它。 该页面还显示可选择的文本。 如果无法使用自动复制,请使用设备的复制命令将文本粘贴到电子邮件应用程序中。

复制不提交查询。 您的操作系统可能会保留剪贴板历史记录或在设备之间同步剪贴板内容,具体取决于您的设置。 该网站不会读取您现有的剪贴板内容。

Cookie、浏览器存储和页面资源

当前的网站脚本不设置 cookie 或使用 localStorage、sessionStorage 或 IndexedDB 来保留查询。 它们不会注册服务工作者或发送分析事件。 页面样式、脚本和图像均来自同一网站;字体使用设备上安装的字体。 当前页面中不包含任何第三方字体服务、嵌入式小部件、分析工具或外部表单服务。

网站没有保存草稿功能。 当恢复标签或会话时,您的浏览器仍可能缓存页面资源、自动填充字段或恢复输入的文本。 这些浏览器功能与我们的查询工具分开。 没有 JavaScript,您可以阅读网站并使用联系人页面的电子邮件模板或直接联系链接;草稿和复制按钮不可用。

托管和技术访问信息

提供网页涉及到向托管基础设施发出请求,托管基础设施接收技术信息,如 IP 地址和请求的 URL。 即使查询表格没有提交您的条目,托管和安全服务也可能保留访问记录。

如果本网站通过 GitHub Pages 提供,GitHub 声明访问者的 IP 地址将被记录并存储以保证安全。 GitHub 页面数据收集(新标签). 本通知未指定托管日志保留期限。

电子邮件,电话,WhatsApp和外部链接

当您向我们发送询问时,IngredientCore会收到您所提供的信息。 您的电子邮件提供商和收件人的电子邮件服务也会处理该消息。 网站缺乏提交端点并不意味着发送给公司的信件从未被收集。 通过电话或WhatsApp联系我们也涉及您选择的通信提供商。 本网站不会自动发送电子邮件或WhatsApp消息,也无法确认消息的递送。

WhatsApp 链接和外部技术参考在您点击时会打开相关的外部服务。 这些服务有其自己的隐私政策。 我们的网页要求浏览器在导航离开时省略引用网页地址;外部服务仍然会收到处理您访问所需的信息。
