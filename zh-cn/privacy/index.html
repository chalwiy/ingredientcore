网站隐私与询盘数据

了解浏览网站、准备询盘和发送邮件时，各环节如何处理信息。

修订日期： 2026年10月3日。

IngredientCore 是鸿源配料有限公司的食品配料出口品牌。鸿源配料有限公司为 Bespring Chemical 的子公司。本说明适用于本网站浏览和询盘工具。

由您选择何时发送询盘

网站在浏览器中生成邮件草稿或可复制的文本。请核对后使用自己的邮箱发送。浏览网页、复制文本和使用邮件服务各涉及不同的数据处理。

  • 您选择提供的信息
  • 询盘链接中的产品与应用信息
  • 生成邮件草稿
  • 复制询盘内容
  • Cookie、浏览器存储和页面资源
  • 网站托管与访问记录
  • 邮件、电话、WhatsApp 与外部链接
  • 隐私咨询与说明更新

您选择提供的信息

表单需要姓名、工作邮箱及产品名称或目标功能。询盘类型包括报价、样品、资料和应用选型。公司、目的地、食品应用、工艺目标、数量、时间、规格和资料用途可按需要填写。

请只提供讨论询盘所需的信息，避免填写机密配方、密码、付款资料或敏感个人信息。如需共享附件，请在您自己的邮件应用或网页版邮箱中添加。

询盘链接中的产品与应用信息

产品页、应用页等站内链接可在网址中携带产品、应用、目标功能、文件、用途或来源页标识。联系页利用这些信息预填表单，并将可识别的来源页加入草稿。

网址可能出现在浏览记录、分享链接或托管日志中，请使用非敏感的产品和应用信息。表单中手动填写的内容不会由本网站脚本写入网址。

生成邮件草稿

表单在浏览器内核对必填字段，并生成询盘文本。您填写的内容保留在打开的页面，由您通过自己的邮箱发送。

点击“打开邮件草稿”后，页面显示完整询盘，并尝试通过 mailto 链接将收件人、主题和正文交给已配置的邮件应用。请自行核对并发送。邮件应用对草稿的保存和同步按其设置处理。

邮件链接无法容纳过长内容时，页面会显示完整文本供复制。实际发送和送达状态请在自己的邮箱中确认。

复制询盘内容

点击“复制询盘内容”后，页面尝试调用浏览器剪贴板功能写入完整文本，包括收件人和主题。浏览器可允许或限制该操作。自动复制不可用时，可选中页面中的文本并手动复制，再粘贴到自己的邮箱。

复制后的文本保留在您的设备剪贴板中。其历史记录和跨设备同步由设备设置决定。网页剪贴板功能仅写入您本次选择复制的内容。

Cookie、浏览器存储和页面资源

网站脚本无需使用 Cookie、localStorage、sessionStorage 或 IndexedDB 来保存询盘，也不注册 Service Worker 或发送分析事件。样式、脚本和图片由本站提供，字体使用设备自带字体。

浏览器本身可能缓存页面资源、自动填充或恢复输入内容。停用 JavaScript 时，可继续浏览网站，并通过联系页的邮件模板或直接联系方式发起询盘。

网站托管与访问记录

打开网页时，托管设施会收到 IP 地址、请求网址等技术信息。托管和安全服务可按其规则保留访问记录。

若网站通过 GitHub Pages 提供，GitHub 说明其为安全目的记录并保存访问者 IP 地址。可查阅 GitHub Pages 数据收集说明了解托管服务的数据处理。

邮件、电话、WhatsApp 与外部链接

您通过邮箱发出询盘后，邮件中提供的信息将由您所选的邮件服务以及收件方的邮件服务处理。电话和 WhatsApp 由相应通信服务处理。发送和送达状态由您使用的服务提供。

点击 WhatsApp 或外部技术资料链接后，会进入相应的网站或服务。外部服务根据自身规则处理访问，本网站请求浏览器省略来源页地址。外部服务仍会接收处理访问所需的信息。

隐私咨询与说明更新

如对网站、已发送的询盘或您提供的信息有疑问，请发邮件至 ingredientcore@bespringchem.com，说明必要的访问或沟通背景。请避免附带无关的敏感信息。

联系地址：江苏省徐州市云龙区Greenland Linghai 6 号楼 10 层，邮编 221000。 查看联系方式与邮件询盘说明。

如果您需要了解已发送询盘的访问范围或保留时间，请在提供需要特殊处理的信息前通过上述邮箱联系。

本说明适用于当前网站工具，页面顶部标有本说明的修订日期。
