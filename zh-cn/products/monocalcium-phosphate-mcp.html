什么是一水磷酸二氢钙？

一水磷酸二氢钙含有一个结晶水，与无水物的形态不同。核对规格书、COA 和样品标识是否都注明一水物。

常用名称：磷酸二氢钙一水物。

买方问题

一水 MCP 采购常见问题

MCP 一定是一水磷酸二氢钙吗？

MCP 也可泛指磷酸二氢钙。若试验需要一水形态，应在样品和供货资料中明确注明。

钙含量可以预测烘焙表现吗？

钙含量描述组成，烘焙表现还受中和值、反应时间、配方和工艺影响。请在目标配方中对照。

干燥失重能代表所有水分吗？

干燥失重应按既定条件解释。采购时将结晶水、游离水分和其他热失重分别核对。

申请一水 MCP 样品需要什么？

注明一水形态、现用膨松体系、从混合到加热的间隔和评价指标，并索取对应规格、TDS、COA 和 SDS。
