产品概述

什么是磷酸二氢铵？

磷酸二氢铵又称磷酸一铵，化学式为 NH₄H₂PO₄。它与磷酸氢二铵（DAP）的成分不同，应按具体用途和检验方法分别比较。

常用名称：磷酸一铵、磷酸单铵。

买方问题

MAP 采购常见问题

MAP 指哪一种磷酸铵？

MAP 是磷酸二氢铵，又称磷酸一铵。订货名称应注明完整名称和所需食品级要求。

P₂O₅ 指标代表 MAP 纯度吗？

以 P₂O₅ 表示的是磷含量，MAP 含量需按相应化合物方法测定。比较时请确认单位、方法和干基或原样基准。

询盘时要指定粉末还是颗粒吗？

可说明现有投料和操作方式，并索取拟供应品级的实际形态、粒度及申报成分。

MAP 能否等量替代 DAP？

MAP 与磷酸氢二铵（DAP）是不同的铵盐。应根据营养和酸碱目标，在完整配方中试验。 了解磷酸氢二铵（DAP）。

申请 MAP 样品和资料需要什么？

提供用途、试验目标、所需规格、数量和目的地，并注明需要的规格书、TDS、COA、SDS 或证书。
